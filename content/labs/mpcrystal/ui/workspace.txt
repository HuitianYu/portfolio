        <div class="overview-layout">
          <section class="overview-description">
            <span class="eyebrow">HOW THE LOOP WORKS</span>
            <h2>
              From the target
              <br />
              to crystal growth.
            </h2>
            <div>
              <h3>Primary controller</h3>
              <p>
                Tracks the selected supersaturation $\sigma$ or growth rate $G$. MPC predicts the
                process response and accounts for time lag; PI uses the tracking error to determine
                the temperature gradient $\dot T_{\mathrm{set}}$.
              </p>
            </div>
            <div>
              <h3>Secondary controller</h3>
              <p>
                Combines the heat-transfer model with jacket feedback to calculate the jacket
                temperature setpoint $T_{\mathrm{j},\mathrm{set}}$.
              </p>
            </div>
            <div>
              <h3>GSensor &amp; adapter</h3>
              <p>
                Simulated growth measurements feed the parameter adapter. When enabled, it updates
                the selected parameters $E_{\mathrm{A}}$, $k_0$ and $n$ used by the control model.
              </p>
            </div>
            <p class="overview-note">
              The diagram shows the complete experimental architecture. This page runs the
              simulation path: temperature, concentration and growth measurements come from the
              process model.
            </p>
          </section>
          <figure class="structure-figure">
            <img
              alt="MPC structure: state filtering, prediction, time-lag correction, objective minimization, jacket control, growth-rate sensor and parameter adaptation"
              src="assets/mpcrystal-control-structure.png"
            />
            <figcaption>
              Model predictive control with growth-rate sensing and parameter adaptation
            </figcaption>
          </figure>
        </div>
        <details class="input-guide">
          <summary>How does this simulation work?</summary>
          <p>
            Each step advances the physical model by $\Delta t$, updates the extended Kalman filter,
            computes the primary control action, and updates the jacket temperature setpoint.
            Growth-rate measurements and adaptation run when enabled. Start controller begins a new
            run; Pause preserves the current state; Refresh controller resets the filters and
            controller integrals while keeping process history.
          </p>
          <p>
            The top-right step interval controls playback only. Add seed adds a new batch to the
            existing crystal population. Advance one step calculates one physical time step $\Delta
            t$ while playback is paused. Initial conditions apply on the next run.
          </p>
        </details>
